# Decentralized Fundraiser

## 🪙 Project Description
**Decentralized Fundraiser** is a blockchain-based crowdfunding platform that allows individuals or organizations to raise funds transparently without intermediaries. Donors can contribute directly in cryptocurrency and track progress in real time on the blockchain.

---

## 🎯 Project Vision
To empower global communities by enabling trustless, transparent, and borderless fundraising using Ethereum smart contracts.

---

## ✨ Key Features
- **Direct Donations:** Anyone can send ETH directly to a campaign.
- **Automatic Goal Tracking:** Smart contract marks the goal as reached once the target is met.
- **Secure Withdrawals:** Only the project owner can withdraw funds after the goal is achieved.
- **Transparency:** All transactions are recorded on-chain and verifiable by anyone.

---

## 🚀 Future Scope
- Support for multiple campaigns within a single contract.
- Integration with front-end DApp for better user experience.
- Multi-token support (ERC20 stablecoins).
- DAO-based governance for community-managed fundraisers.
